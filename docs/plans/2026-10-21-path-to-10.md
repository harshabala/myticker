# MyTicker: path to 10

Date: 2026-10-21. Branch `harsha/path-to-10`, cut from `main` at `d9077d3` (v0.5.0).

## What it is for

MyTicker is a Manifest V3 Chrome extension for retail investors, mainly Indian ones with a Zerodha account (Groww, Upstox and generic CSVs also work, plus US stocks and a small crypto catalogue), who want to see how their portfolio is doing without opening a broker app. They export a holdings CSV, drop it into Settings, and a thin Ticker Tape across the top of every web page shows each holding's price, day change and day P&L, with a popup "scoreboard" for the day total and top movers. Indian prices come from Yahoo without a key; US prices need a free Finnhub key, which is encrypted locally under an unlock code. Everything stays in the browser: there is no server and no telemetry.

## Baseline (before this work)

Commands run at `d9077d3` with Node 26.8.2: `npm ci` (0 vulnerabilities), `npm run verify` (check, lint, version, scan, tests) all green, **97/97 tests pass**. Line coverage from `node --test --experimental-test-coverage`: 52% overall; `background.js` 35%, `popup.js` 47%, `onboarding.js` 18%, `options.js` not loaded by any test. No test had ever loaded the extension in a browser.

Loading the unpacked extension in headless Brave (Chromium 155) for the first time found three user-facing bugs that every test missed:

1. **Settings was broken on every load.** `options.js` called `init()` at the top of the module; the lint cleanup in `d9077d3` moved `DATA_PANEL_IDS` to a module `const` below that call, so `init()` threw `ReferenceError` (temporal dead zone) and no Settings control was wired.
2. **The Ticker Tape never appeared on a fresh install** until some setting was saved. The content script treated "no `pts_settings`" as "off"; the worker and popup treat it as the enabled default. The Zerodha/India path (no Finnhub key) never saves settings.
3. **Every page jumped down ~360px while `ticker.css` loaded**: the unstyled bar's stacked items were measured and reserved as page margin.

Also found: a developer-only "Import packaged holdings" button that every user could see (`.btn` display overrode `hidden`) and that could only 404, and light-theme P&L colours at 4.0-4.4:1 contrast (WCAG AA needs 4.5:1).
